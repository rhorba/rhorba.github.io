Vous reconnaissez votre système ?

Si trois de ces phrases sont vraies chez vous, un audit se rentabilise avant même la première ligne de code changée.

  • L'application tourne en JSF/PrimeFaces sur WildFly ou JBoss, et plus personne dans l'équipe n'a envie d'y toucher.
  • La montée de version Java, Spring ou Oracle est repoussée d'année en année ; le support éditeur, lui, s'est arrêté.
  • Les déploiements se font à la main, le soir, et une seule personne sait les refaire.
  • Les processus métier vivent dans Activiti ou un moteur BPMN, et celui qui les avait modélisés est parti.
  • Vous voulez passer à Spring Boot, mais vous ne pouvez pas geler les évolutions métier pendant six mois.
  • Les tests existent « quelque part », sans que personne ne sache ce qu'ils couvrent réellement.
